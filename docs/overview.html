③ Obsidian 연동 방식 (당신 질문)

네, 기존 vault에 그대로 연동됩니다. obsidian_vault에 기존 vault 루트만 지정하면, 그 안에 프로젝트 전용 폴더를 만들어 모읍니다. 기존 노트는 건드리지 않습니다(테스트로 검증).

내_기존_Vault/
├─ Daily.md                  ← 기존 노트 그대로 보존
└─ Effect-of-compound-X.../   ← rpaper 가 만든 프로젝트 폴더
   ├─ 00-Index.md            (프로젝트 허브 MOC)
   ├─ Bibliography.md        (번호순 전체 인용)
   ├─ References/Ref-001.md  (요약·abstract·Vancouver 인용·^ref-001)
   ├─ News/...
   ├─ Manuscript/Introduction.md, Results.md ...
   └─ .rpaper/               (캐시·references.bib)

인용 링크는 [[폴더/References/Ref-001|1]]처럼 경로까지 명시 → 다른 프로젝트와 노트명이 겹쳐도 모호하지 않음. 모바일/PC 어느 동기화에서도 동일하게 열림.

④ 사용법

pip install -e .
cp config.example.yaml config.yaml   # 키/경로 입력
rpaper collect          # 수집 → Obsidian 위키 + BibTeX
rpaper analyze data.csv group value  # 통계(유의성)
rpaper figure  data.csv group value  # R figure
rpaper write intro      # intro|methods|results|discussion
rpaper journal          # 저널 템플릿+가이드라인
rpaper status           # 진행률·키 설정 한눈에
rpaper run              # collect + intro/methods 일괄

⑤ 🗓️ 화요일 아침 — 당신이 추가할 것만

  • config.yaml 작성: obsidian_vault(기존 vault 경로), title/keywords
  • Anthropic API 키 (ANTHROPIC_API_KEY) — 요약·원고 품질의 핵심
  • (선택) SerpAPI(Scholar) / NewsAPI(뉴스) / NCBI 키
  • (선택) bash scripts/setup.sh 로 R + ggplot2 설치 — figure·정확 p값
  • 당신만 줄 수 있는 것: raw data CSV, 저널 template/guideline URL, figurelabs API 문서
