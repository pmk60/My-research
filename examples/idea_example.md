# 아이디어 예시: 모듈형 접이식 자전거 잠금장치

기존 자전거 U자 잠금장치나 체인 잠금장치는 무겁고 부피가 커서 휴대가 불편하다.
케이블 잠금장치는 가볍지만 절단에 취약하다.

내가 생각한 것은 짧은 금속 분절(링크) 여러 개를 이어 만든 접이식 잠금장치인데,
핵심은 각 분절의 연결부를 **강력한 영구자석 + 기계식 래치**로 결합한다는 점이다.
평소에는 분절들을 접어 손바닥만 한 모듈로 만들어 안장 밑 거치대에 자력으로 부착해
휴대하고, 사용할 때는 펼쳐서 프레임과 거치대를 감싼 뒤 양 끝을 잠근다.

추가로, 잠금부에 진동 센서와 블루투스 모듈을 넣어 절단·충격을 감지하면
스마트폰으로 알림을 보내는 기능도 생각하고 있다.

기대 효과: 케이블보다 절단 저항이 높으면서도, U자 락보다 가볍고 휴대가 간편하다.
